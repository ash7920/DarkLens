DarkLens: auditing EU e-commerce websites for dark patterns

Crawl-and-verify LLM pipeline. Revised scope: crawlable EU retailers human-validated; bot-blocked sites reported as coverage. Same pipeline scales to 500 sites.

1. Data sources

Existing labelled datasetsEC dataset (Yada 2022): 2,356 texts
Mathur 2019: 1,818 instances
AidUI/ContextDP: 501 screenshots
EU e-commerce websites136 retailers attempted; crawlable ones human-validated
bot-blocked sites reported, not counted
Controlled test-bedDarkMart (43 injected patterns) + FairMart clean twin

2. Crawling & collection

Playwright crawlerPriority-guided BFS (checkout > cart > product > category); multilingual page classifier
Safe interactionOpens cookie layers, pop-ups, expanders, add-to-cart. Never pays, orders or signs up
Per page stateHTML · visible text · UI elements (bbox, size, colour, checkbox state) · screenshot + metadata

3. Preprocessing

HTML/text cleaningUnicode normalisation, de-duplication, boilerplate filter
UI segment extractionEach text / button / checkbox becomes a segment with its UI state: "[checkbox, PRE-TICKED]"
Visual cuesChoice-prominence asymmetry (big "Accept" vs tiny "reject")
Unified datasetOne schema for public data + crawl

4. Detection

Candidate pre-filterRule lexicon + TF-IDF classifier (cuts LLM calls)
LLM: infer → verifyInfer category for each segment, then a verification pass rejects false positives (after DPDGPT)
OutputsCategory · evidence quote · confidence · explanation · location
UrgencyScarcityConfirmshamingPre-ticked add-onsDifficult cancellationSocial proofInterface interferenceForced action

5. Evaluation

Human ground truth2 annotators label a stratified sample blind; 3rd adjudicates
MetricsPrecision · recall · F1 (binary + per category) · Cohen's κ (LLM vs human, human vs human)
ComparisonsRules vs TF-IDF vs RoBERTa vs LLM · single-pass vs verify · test-bed · AidUI screenshots

6. Findings & tool

PrevalenceBy category, page type, country, sector (lower bound)
Error analysisFP/FN with the model's own explanation
DarkLens web appUpload a screenshot or URL → verdict, marked locations, EU legal pointers
